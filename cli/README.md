# bk コマンド

家計簿は `bk` のコマンドで使う（本人決定 2026-11-08、TUIは2026-11-09に削除。Gitの `a346668` まで）。
`bk` は `./tools/household` で、押し出し済みの `origin/main` を手元でビルドして動かし、終わると
家計簿をcommitしてprivateのバックアップへpushする。`bk help` が一覧を出す（打ち間違えても一覧を出す）。

どのコマンドも1行ずつ聞き、保存の前に必ずPreviewを見せ、Enterで保存する。`n` やCtrl-Dなら何も
保存しない。読み込んだ後に帳簿が変わっていたら上書きしない。名前は表示名で出し、中のIDは
同じ表示名が2つあるときだけ添える。いくつかから選ぶとき（口座・予定・流れ・記録・Attention）は
どれも同じ：9つまで番号を出し、Enterで1番、番号でそれ、ほかの入力で絞り、1つになればそれを取る。
表は表示幅（漢字・かなは2マス）で揃える。記録は通帳の型で出す：見出しの下に、どこから（from）
どこへ（to）と符号なしの金額を1回だけ書き、内訳や両替は次の行に続ける。規則はすべて
`household/` のコアにあり、`bk` は聞く・コアに渡す・Previewを見せる・保存するだけ。

## 記帳

- `bk r`：実績。科目は表示名かIDの先頭で選ぶ（いくつかあれば番号）。金額でEnterを押すと
  釣り合う額。前に使ったメモなら、そのときの行を選べる（最後の行は上の行に合わせて釣り合う）。
  Saveで `o` を押すと元の通貨の金額（Original）を付けられる。保存後「Record another?」。
- `bk pay`：予定の支払い。期限の古い順に出し（期限切れに `overdue`）、Enterで予定どおり、
  `e` で行を直す。名前の先頭で絞れる。保存後「Pay another?」。
- `bk fx`：両替（出た口座・Measure・金額と、入った口座・Measure・金額。レートは保存しない）。

## 直す

記録は `bk find` と同じ語で絞り、新しい順の番号で選ぶ。

- `bk edit`：行・メモ・日付の訂正。`bk date`：日付だけ。`bk refund`：返金（元を残し、逆の記録を
  つなげて足す）。`bk shop`：店の分類（1回だけ）。

## 見る

- `bk`：今日の目安とコマンドの一覧。`bk pace`：今日の目安とその内訳。
- `bk bal`：残高（`balance-view.tsv` の口座、なければ全口座×全Measure。わからない残高は `?`）。
- `bk last [件数]`：最後に保存した記録（既定は10件）。通帳のように一番新しいものが一番下。並びは保存した順で、
  日付の順ではない（先週の日付で今保存したものも一番下）。訂正しても位置は変わらない。
- `bk find <語>…`：記録の検索。どの語も満たす記録。口座名・メモの一部、期間（`2026`・`2026-10`・
  `2026-10-05`・`A..B`）、`acct:`・`memo:`・`date:`・`amt:1200`・`amt:1000..`。書き方は
  `test/queries/README.md`。
- `bk reg <口座> [語]`：口座の記録を通帳の2列で：減った額はout、増えた額はinに符号なしで1回だけ。その日の
  終わりの残高はその日の最後の行に（わかる所だけ。わからなければ `?`）。
- `bk month [期間]`：月ごとの収支（支出のうち予定の支払い分）。既定は直近6か月。
- `bk report ie [期間]`：1つの期間の収支を科目ごとに。既定は今の周期。
- `bk day [日付]`：ある日の記録と期限の予定。

## 予定

- `bk plans`：予定の流れ（同じ口座の組のまだの予定）ごとに、次の期日・どこまで入っているか・残りの数。
  `scheduled-coverage.tsv` で見守る流れは周期と最初の抜けた月も。
- `bk plans more`：補充（その月に同じ日がなければ日付を聞く）。`bk plans amount`：ある日からの
  一括の金額変更。`bk plans cancel`：選んだ予定の一括取り消し（`2-4 6` のように選ぶ）。

## 設定と口座

- `bk pace pool`：今日の目安に入れる口座（残高が正確な口座から）。`bk pace cycle`：今の周期の境目。
  `bk pace if <金額>`：買ったら（`+金額` は入金）。`bk pace target`：目標のペースを守る1日の額。
- `bk check`：見た残高（銀行アプリや財布）を口座ごとに入れる。記録から決まる残高は比べて差を
  見せるだけで、差は `bk r` で記帳する。
- `bk loci`：口座の一覧と残高（記録・予定・残高の根拠があるMeasureごとに1行）。`add`・`name`・`role` で追加・表示名・役割（役割は1回だけ）。
- `bk todo`：期限のある家計の用事。`add`・`done`・`drop`。

## 設定ファイルと検証

設定ファイル（`daily-pace.tsv`・`boundary-presets.tsv`・`balance-view.tsv`・
`scheduled-coverage.tsv`）は帳簿の横の `config/` にあればそこ、なければ帳簿の横。

```sh
./tools/check                    # ビルド、見本、bkの合成検査、privacy-scan
./ui [COMMAND]                   # 家計簿のコピーでbkのコマンド（./tools/household-copy refresh の後）
./ui --demo [COMMAND]            # 合成の帳簿で
```

`cli/test/line_commands_checks.ml` が全コマンドを合成の帳簿と台本の入力で確かめる。
`cli/test/views.ml` は合成した1年分の家計で、読むだけのコマンドの表示を全部
`cli/test/views.expected` と比べる（表示を変えたら差分を読んで `dune promote`）。
実際の端末での日本語入力（IME）は確かめていない。
