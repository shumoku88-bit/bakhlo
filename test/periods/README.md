# 期間の見本

日・月・年・全期間と、家計が `boundary-presets.tsv` に書いた周期（給料日から次の給料日の
前日まで、など）を、言語に依存しない問いと答えで書く。Actualの期間バーと期間選択、報告、
Daily Paceの今日の目安とHistoryは、すべてこの決まりで期間を選ぶ。中身はすべて合成。
Bakhloでの確認は `test/periods_tests.ml`、実装は `household/period.ml`。

## boundary-presets.tsv

```
pay	2027-01-25	2027-02-25	2027-03-25	2027-04-25
```

1行が1つのpreset：名前と、2つ以上の境界日をタブで区切る。隣り合う2つの日付が1つの窓になり、
始まりの日を含み、終わりの日を含まない。この行は [01-25, 02-25)・[02-25, 03-25)・[03-25, 04-25)
の3つの窓になる。

- 行の前後の空白とCRは無視する。空行と `#` で始まる行は読み飛ばす（`messy`）。
- 名前は空白を含まない1語で、ファイルの中で重複しない。境界日は `YYYY-MM-DD` の実在する日付で、
  増えていく順。1行でも違えば、ファイル全体を `malformed` として拒否する（`ng-*`）。
- ある日の周期は、その日を含む窓を持つpresetがちょうど1つのときだけ決まる。1つもなければ
  `no-cycle:<日付>`、2つ以上なら `ambiguous:<日付>` で拒否し、どちらかを選ばない（`two-presets`）。
- ファイルがなければ `not-configured`。周期を使わない問い（日・月・年・全期間・直近の日数・
  今月）は、ファイルがなくても壊れていても答える。

## 1つの見本

問いはすべて1行（書き方は `test/README.md`）。`USE	PRESETS	<ファイル>` が周期のファイルを決める。

```
CYCLE	2027-02-10	pay	2027-01-25	2027-02-25
```
その日の周期：presetの名前と、その日を含む窓。

```
WINDOW	2027-02-10	MONTH	-1	2027-01-01	2027-02-01
```
その日を含む期間を、期間の数だけ前後に動かした窓（始まり、終わり（含まない））。期間は
`DAY`・`MONTH`・`YEAR`・`CYCLE`・`PREVIOUS-CYCLE`（今の周期の1つ前）・`ALL`
（0001-01-01から9999-12-31（含まない）まで）。月と年は1日・1月1日から始まる。周期が
設定された窓の外へ出れば `outside-presets`、暦が0001〜9999年の外へ出れば `out-of-range`。

```
RANGE	2027-03-01	PREVIOUS-CYCLE	2027-01-25	2027-02-24
```
Daily Pace Historyが並べる日（最初の日と最後の日、どちらも含む）。範囲は `LAST-DAYS-<n>`
（今日までのn日）・`MONTH-TO-DATE`・`CYCLE-TO-DATE`・`PREVIOUS-CYCLE`（前の周期の全部）。

```
ELAPSED	2026-10-15	2026-10-01	2026-11-01	15	31
```
収支比較の窓（始まり、終わり（含まない））の経過日数と全日数。今日を含み、未開始なら0、
完了なら全日数。日付が不正なら両方0。

```
SAME-AGE	2026-09-01	2026-10-01	15	2026-09-01	2026-09-16
```
同じ経過日数で比較する窓：始まりを保ち、その日数後を終わり（含まない）にする。
0日以下は空の窓。元の終わりでは切らない（31日なら10月2日まで）。
日付の移動に失敗したときだけ元の窓を保つ。

答えられないときは、答えの代わりに `REFUSED	<理由>` を書く。
