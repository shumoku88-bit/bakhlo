# 記録の検索の見本

`bk find` が記録をどう絞り込むかを、言語に依存しない問いと答えで書く。すべて合成で、答えは手書き。
書き方は `test/README.md`、実装は `household/query.ml`、確認は `test/queries_tests.ml`。
考え方は hledger の検索にならうが、語はすべて満たす（AND）。

- `FIND	<語>…`（ブロック）：どの語も満たす記録を、記帳順に `ENTRY	<ID>` で答える。語がなければ全部。
  書けない語は `REFUSED	<コード>`。
- ただの語：口座のIDか表示名、またはメモに含まれる（ASCIIの大文字小文字は区別しない）。
- `acct:<語>`：口座だけ。`memo:<語>`（`desc:` も同じ）：メモだけ。
- 期間：`2026`・`2026-10`・`2026-10-05`、`A..B`（それぞれの始まりの日から、Bの始まりを含まない。
  どちらかを空にすると開いた期間）。`date:` を付けても同じ。数字とハイフンと点だけで年から
  始まる語は期間として読み、正しくなければ `bad-date:<語>`。
- `amt:<金額>`：どれかの行の大きさ（符号を除く）をそのMeasureの単位で比べる。`A..B`（Bを含まない、
  どちらかは空でもよい）の範囲は1つの行が満たす。`>`・`>=`・`<`・`<=` も前に付けられ（シェルでは
  引用符が要る）、何もなければ等しい。書けない金額は `bad-amount:<語>`。
- 知らない `名前:` は `unknown-field:<名前>`、`acct:` などの後が空なら `empty-term:<語>`。
