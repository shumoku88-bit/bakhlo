# 答えの見本の書き方

このディレクトリの6つのフォルダ（`amounts`・`common_format`・`periods`・`reports`・
`records`・`scheduled`）は、家計の規則を言語に依存しない問いと答えで書いた仕様。どの実装も
全部通ればBakhloと同じ答えを出す。中身はすべて合成で、答えは手で書く。実装の出力を
写して答えにしない。各フォルダのREADMEは、そこで聞く問いの種類と規則だけを書く。

## 答えのファイル

`*.answers` はUTF-8のテキストで、1行ずつ読み、欄はtabで区切る。

- `#` で始まる行と空の行は覚え書き。読む側は無視し、その位置のまま残す。
- `USE	<名前>	<ファイル>` は、それより後の問いが使うファイルを決める（`USE	BOOK	base.txt`、
  `USE	PRESETS	pay.tsv`）。ファイルがないことは `-` と書く。同じ名前の次の `USE` まで続く。
- 問いは1行か1ブロック。
  - 1行の問い：種類、問いの欄、答えの欄を1行に並べる（`POSITIVE	0	(500+300)/2	400`）。
  - ブロックの問い：`<種類>	<問いの欄>` の行、入力の行、答えの行、`END<種類>` の行。入力と答えの
    境が種類だけで決まらないときは、その間に `ENDINPUT` の行を置く。

どの種類がブロックかは、フォルダごとに決まっている（各README）。

## 正しさ

実装は各問いの答えを計算し、ファイル全体を同じ形で書き直す。書き直した文字がファイルと
1バイトも違わなければ正しい。違えば最初に違う行を `FAIL <フォルダ>/<ファイル>:<行>` で示す。
帳簿や周期の設定そのもの（`*.txt`・`*.tsv`）と、変更後の帳簿（`*.after.txt`）は、bytesが
問題になるのでファイルのまま置く。

Bakhloでは `test/samples.ml` がこの読み書きだけを持ち、各フォルダの確認
（`test/*_tests.ml`）は問いの種類ごとの答え方だけを持つ。
